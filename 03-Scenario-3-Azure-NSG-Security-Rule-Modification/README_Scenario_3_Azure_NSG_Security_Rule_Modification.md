# 🌐 Azure NSG Security Rule Modification

## 📌 Overview

This scenario focuses on detecting and investigating modifications to **Azure Network Security Group (NSG) rules** using **Azure Activity Logs** and **Microsoft Sentinel**.

Unauthorized NSG modifications can expose cloud resources and increase the attack surface. This scenario demonstrates detection, investigation, incident creation, and automated response.

---

## 🎯 Objective

- Monitor Azure NSG security rule changes
- Detect rule creation, modification, and deletion
- Identify the user who performed the change
- Identify the affected NSG and rule
- Generate a Microsoft Sentinel incident
- Apply automated incident response actions

---

## 🚨 Detection Logic

The following Azure operations were monitored:

```text
Microsoft.Network/networkSecurityGroups/securityRules/write

Microsoft.Network/networkSecurityGroups/securityRules/delete
```

---

## 🔍 Detection Query

```kql
AzureActivity
| where OperationNameValue in~ (
    "MICROSOFT.NETWORK/NETWORKSECURITYGROUPS/SECURITYRULES/WRITE",
    "MICROSOFT.NETWORK/NETWORKSECURITYGROUPS/SECURITYRULES/DELETE"
)
| where ActivityStatusValue =~ "Success"
| extend NSGName = tostring(split(Resource, "/")[0])
| extend RuleName = tostring(split(Resource, "/")[1])
| project TimeGenerated, Caller, OperationNameValue, Resource, Properties, NSGName, RuleName
| order by TimeGenerated desc
```
